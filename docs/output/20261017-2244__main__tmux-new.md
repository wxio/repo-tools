`repo-tools tmux new -s <name>` now makes a tmux session and attaches to it. The change is in the working tree and is not staged, with the uncommitted `tmux` work from the last prompt.

**What it does.**

- Outside tmux, it runs `tmux new-session [-s name]` with the terminal.
- Inside tmux, it runs `new-session -d -P -F '#{session_name}'`, then `switch-client -t <name>`. Without this, tmux refuses to nest the client. The `-P` output gives the name when tmux picks it.

**`-s` on `new` is a plain string, with no completion.** The name of a new session is not one of the names that exist.
